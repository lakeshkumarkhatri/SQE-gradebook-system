# Contributing to SQE GradeBook

The project uses a feature-branch workflow to keep the `main` branch stable and releasable. New functionality should be developed in branches using the `feature/<slug>` naming convention, bug fixes should use `fix/<slug>`, and documentation changes should use `docs/<slug>`. Changes should be committed using clear Conventional Commits messages and submitted through a Pull Request before being merged into `main`. The detailed branching and review process will be defined and expanded in later SQE labs.
