# Code Review Checklist

## 1. Correctness
- [ ] Does the code implement the required functionality correctly?
- [ ] Are calculations and logical conditions correct?

## 2. Tests
- [ ] Are appropriate unit tests included for the new functionality?
- [ ] Are edge cases and invalid inputs tested?

## 3. Readability
- [ ] Are variable and method names clear and meaningful?
- [ ] Is the code properly formatted and documented where necessary?

## 4. Design
- [ ] Does the implementation follow the existing project structure?
- [ ] Is unnecessary code duplication avoided?

## 5. Risk
- [ ] Could the changes break existing functionality?
- [ ] Are potential performance or security issues considered?
